---
name: Auction status layout
description: The user's layout constraint for the countdown and latest-bid area.
---

Keep the countdown above the bid list. Do not put the countdown and bids side by side, and do not give the current bid a separate card layout. Use the same row structure for the latest/winning bid and previous bids; distinguish the current row through hierarchy (such as weight and contrast), not a different layout. Avoid boxed containers for this information.

**Why:** The user explicitly rejected side-by-side placement, separate containers, and the mismatch between the current bid and the history rows.

**How to apply:** Keep the countdown first, then show the latest/winning bid in the same unboxed row style as the history, using only typographic emphasis to establish priority.
