name: Auction status layout
description: The user's layout constraint for the countdown and latest-bid area.

Keep the countdown panel above the latest-bid panel. Do not place these two panels side by side.

**Why:** The user explicitly rejected the side-by-side arrangement and corrected a prior attempt that only moved the bid timestamp.

**How to apply:** Preserve the vertical order of countdown first and latest bid second when revising the main auction status, including at wider viewport sizes.
